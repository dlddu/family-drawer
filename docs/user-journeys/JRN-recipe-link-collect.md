## 1. 서비스 개요 (참고)

**family-app-gym-recipes** — 가족이 "놓치면 다시 하기 번거로운 일"을 놓치지 않게 돕는 가족용 앱.
제품 개요·가치·범위는 [`family-app-gym-recipes-values.md`](../product/family-app-gym-recipes-values.md) 참조.

이 여정은 **유튜브 앱의 공유 시트가 입구**다. 앱 안에서 영상을 검색하는 흐름이 아니다.

## 2. 여정 정의

**대상 사용자 (페르소나)**
두 역할이 한 여정에 함께 등장한다.

- **공유자** — 예를 들어 엄마. 유튜브에서 요리 영상을 자주 보고, 괜찮으면 가족에게 보낸다. 앱 설정을 파고들지 않고 "공유" 버튼까지만 쓴다. 손이 젖어 있거나 요리 중인 경우가 많다 **(가정)**.
- **소비자** — 그 레시피로 실제 요리하는 사람. 공유자와 같은 사람일 수도, 다른 가족 구성원일 수도 있다. 가족 인원·구성은 미확정 **(가정)** 이므로 "두 사람"으로 전제하지 않는다.

**진입 맥락**
① 유튜브 앱에서 영상을 보다가 공유 → 이 앱 선택 (저장 흐름), 또는 ② 장을 보거나 요리를 시작하면서 앱의 보관함을 연다 (꺼내는 흐름).

**트리거**
"이거 해 먹어 봐야겠다" 하는 순간(저장), 또는 "그때 그 영상 뭐였지" 하는 순간(열기).

**사용자 목표**
본 영상을 잊지 않게 남기고, 요리할 때 **그 영상의 그 지점**을 다시 연다.

**완료 기준**
관찰 가능한 이벤트:
① 저장 흐름 — 공유로 들어온 링크가 보관함 항목으로 저장되고 저장 피드백 문구가 노출됨, 또는 중복으로 판정되어 기존 항목으로 이동함.
② 열기 흐름 — 보관함 항목에서 `원본 보기` 로 유튜브(앱 또는 브라우저)가 열림.

## 3. 단계별 상세

> 단계 식별자는 순번이 아닌 슬러그를 쓴다. 순서가 바뀌어도 식별자는 유지한다.

### `STP-share-from-youtube` 유튜브에서 이 앱으로 공유

- **사용자 행동**: 유튜브 앱에서 영상 하단 `공유` → 공유 시트에서 이 앱을 고른다
- **터치포인트**: 유튜브 앱 영상 화면, OS 공유 시트, 앱의 전환(공유 수신) 화면
- **시스템 응답**: 앱이 전면으로 뜨고 **로그인·온보딩 없이 바로 저장 확인 화면**으로 간다. 공유 payload 는 URL 단독이 아니라 "제목 + 줄바꿈 + URL" 문자열일 수 있으므로 문자열 전체를 받는다 (AC-R1, AC-R2)
- **생각·감정**: "이거 저장만 해두면 되는데" — 흐름이 끊기면 그 자리에서 포기한다
- **페인포인트 / 이탈 위험**: 공유 시트에 앱이 안 보이거나, 들어가자마자 로그인을 요구하면 끝 → 공유 수신 경로에서는 인증을 요구하지 않는다. 탭 3회 이내(공유·앱 선택·저장)로 끝낸다

### `STP-confirm-save` 받은 링크 확인하고 저장

- **사용자 행동**: 자동으로 채워진 제목을 보고 그대로 `저장` 을 누른다. 원하면 제목을 고치고 메모("고추장 1T로 줄이기")나 태그를 붙인다
- **터치포인트**: 저장 확인 화면(제목·메모·태그 입력, 공유자 라벨), 중복 배너, 오류 상태, 저장 완료 토스트
- **시스템 응답**: 문자열에서 유튜브 링크를 찾아 `videoId`(11자) + `startSeconds` 를 뽑고 `si`·`list`·`index` 는 버린다 (AC-R2). videoId 로 중복을 판정한다 — 이미 있으면 새 항목을 만들지 않고 "이미 보관함에 있는 영상이에요" + `기존 항목 보기` · `메모만 추가` (AC-R3). 유튜브 링크가 아니거나 videoId 추출 실패면 이유를 구분해 보여주고 **원문을 잃지 않는다** (AC-R4). 제목 조회가 실패하거나 오프라인이어도 **저장은 성공**한다 (AC-R9). 모든 문구는 PRD §5 표 그대로 (AC-R7)
- **생각·감정**: "어? 이미 저장했었나" / "제목이 안 뜨는데 저장은 된 거야?" — 앱이 뭘 했는지가 불안의 핵심
- **페인포인트 / 이탈 위험**: 같은 영상이 여러 링크 형태(`watch?v=`, `youtu.be/`, `?si=` 붙은 것)로 중복 쌓이면 보관함이 무너진다 → 중복 판정을 **URL 문자열이 아니라 videoId** 로 한다. 실패를 조용히 처리하면 사용자는 저장된 줄 알고 잃는다 → 네 가지 실패를 각각 다른 문구로 표시한다

### `STP-browse-collection` 보관함에서 레시피 찾기

- **사용자 행동**: 앱을 열어 보관함 목록을 훑거나, 검색어·태그·공유자 라벨로 좁힌다
- **터치포인트**: 보관함 목록 화면(최근 저장순), 검색 입력, 태그·공유자 필터 칩, 빈 상태 화면, 결과 0건 화면
- **시스템 응답**: 필터가 걸린 상태를 칩으로 보여주고, **항목 0개**와 **결과 0건**을 서로 다른 문구로 구분한다 (AC-R8). 항목마다 공유자 라벨을 보여주고 라벨로 필터할 수 있다 (AC-R10)
- **생각·감정**: "엄마가 보내준 거였는데" — 기억의 단서는 제목이 아니라 **누가 보냈는지**인 경우가 많다
- **페인포인트 / 이탈 위험**: 제목이 "제목 없음"인 항목이 쌓이면 찾을 수 없다 → 메모·태그·공유자 라벨을 검색 대상에 포함하고, "제목 다시 불러오기" 경로를 목록에서도 제공

### `STP-open-original` 원본 유튜브 다시 열기

- **사용자 행동**: 항목을 탭해 상세를 보고 `원본 보기` 를 누른다. 요리하면서 메모를 같이 본다
- **터치포인트**: 항목 상세 화면(제목·메모·태그·공유자·저장일·시작시간), 유튜브 앱, 브라우저(대체 경로)
- **시스템 응답**: 유튜브 앱으로 해당 영상을 열고, `startSeconds` 가 있으면 그 지점부터 시작한다. 유튜브 앱이 없으면 브라우저로 열고 "유튜브 앱이 없어서 브라우저로 열었어요" 토스트를 띄운다 (AC-R5). 열기에 실패하면 삭제·비공개 상태 배지를 붙이고 사용자가 쓴 제목·메모·태그는 그대로 유지한다 (AC-R6)
- **생각·감정**: "그 양념 비율 나오는 데가 어디였지" — 영상 처음부터 다시 찾는 건 원하지 않는다
- **페인포인트 / 이탈 위험**: 시작시간을 버리면 매번 처음부터 찾아야 한다 → `t` 파라미터를 저장·복원한다. 영상이 사라졌을 때 항목만 깨진 채 남으면 보관함을 못 믿는다 → 상태를 배지로 알리고 메모는 지킨다

### `STP-fix-entry` 잘못 저장된 것 정리

- **사용자 행동**: 중복으로 들어온 항목을 합치거나, 깨진 링크를 수정하거나, 더는 필요 없는 항목을 삭제한다
- **터치포인트**: 항목 상세의 `⋯` 액션 시트(수정·링크 수정·삭제), 삭제 확인 모달, 삭제 완료 토스트(되돌리기)
- **시스템 응답**: 삭제는 확인 모달을 거친다. 삭제 후 토스트에서 되돌릴 수 있다. `링크 수정` 은 저장 확인 화면과 같은 정규화·중복 판정을 다시 통과해야 한다 (AC-R6, AC-R2, AC-R3)
- **생각·감정**: "잘못 눌러서 지우면 어떡하지" — 되돌릴 수 있어야 정리를 한다
- **페인포인트 / 이탈 위험**: 확인 없는 삭제는 가족 공용 기록에서 치명적이다(내가 지운 것이 남의 레시피일 수 있다) → 확인 모달 + 되돌리기 둘 다 둔다

## 4. 분기·예외 흐름

| 상황 | 처리 | 이어지는 단계 |
|---|---|---|
| 중복 링크 (같은 videoId) | 새 항목 만들지 않고 중복 배너 + `기존 항목 보기` · `메모만 추가` | `STP-browse-collection` 또는 `STP-confirm-save` 재진입 |
| 중복 + 다른 시작시간 | 중복으로 보되 새 시작시간을 기존 항목의 표시 구간으로 추가 제안 | `STP-confirm-save` |
| 유튜브 링크가 아님 / 링크 없는 텍스트 | "유튜브 영상 링크를 찾지 못했어요" + `받은 내용 그대로 메모로 저장` | `STP-confirm-save` |
| 유튜브 도메인이지만 videoId 추출 실패 (잘린 링크, 채널·검색 URL) | "링크가 중간에 끊긴 것 같아요" + 원문 표시 + `원문 그대로 저장` | `STP-confirm-save` |
| 제목 조회 실패 / 오프라인 | 링크만 먼저 저장 성공 + 인라인 안내 + 나중에 `제목 다시 불러오기` | `STP-browse-collection` |
| 중도 이탈 (저장 화면에서 앱 종료) | 다음 실행 시 받은 링크를 임시 보관 상태로 되살려 이어하기 | `STP-confirm-save` |
| 유튜브 앱 미설치 | 브라우저로 열고 토스트 안내 | `STP-open-original` |
| 영상 삭제·비공개 | 상태 배지 + 메모 보존 + `링크 수정` · `삭제` | `STP-fix-entry` |
| 보관함이 비어 있음 | 빈 상태 문구 + 유튜브에서 공유하는 방법 안내 | `STP-share-from-youtube` |
| 검색·필터 결과 0건 | 결과 0건 문구 + `필터 지우기` | `STP-browse-collection` |
| 삭제 실수 | 확인 모달 + 삭제 후 토스트의 되돌리기 | `STP-fix-entry` |
