## 1. 서비스 개요 (참고)

**family-app-gym-recipes** — 가족이 "놓치면 다시 하기 번거로운 일"을 놓치지 않게 돕는 가족용 앱.
제품 가치는 [`family-app-gym-recipes-values.md`](../product/family-app-gym-recipes-values.md), 제품 목표·범위와 가치 하위 기준은 [부록](../product/family-app-gym-recipes-values-appendix.md) 참조.

이 여정에서 앱이 하는 일은 넷이다: 접수 기간 알려주기 · 준비물 확인 · 공식 신청 페이지로 보내기 · 결과 기록.
**신청과 결제는 앱이 하지 않는다**(확인/가정 구분은 사실 근거 문서 A-6 절).

## 2. 여정 정의

**대상 사용자 (페르소나)**
가족 중 **신청자** 역할을 맡은 사람. 부천 거주 (가정) 이고, 집 근처 부천도시공사 체육센터 헬스를 월 단위로 끊어 다닌다.
공식 사이트를 쓴 적은 있지만 "언제부터 접수였는지"를 매달 헷갈린다. 다른 가족 구성원(예: 중학생 자녀, 배우자)의 등록도 대신 챙길 수 있다 **(가정)**.

**진입 맥락**
① 월말·월초에 "등록해야 하는데" 하고 앱을 직접 연다, 또는 ② 앱이 보낸 재등록 알림을 탭해서 들어온다.

**트리거**
이번 달 이용 기간이 끝나간다는 자각, 또는 재등록 기간 시작 1일 전 알림(AC-G7).

**사용자 목표**
접수 기간 안에, 막히는 조건 없이, 공식 경로에서 신청을 끝내고 그 사실을 가족 기록으로 남긴다.

**완료 기준**
관찰 가능한 이벤트 두 개가 모두 일어남:
① 사용자가 공식 신청 페이지를 열었다(앱의 CTA 이동 이벤트), ② 돌아와서 결과를 `신청 완료`/`대기·미정`/`실패` 중 하나로 기록했다(AC-G6).
→ 기록 시점에 다음 재등록 알림이 예약되면 여정이 닫힌다(AC-G7).

> 앱은 공식 사이트의 실제 신청 성공을 알 수 없다. 그래서 완료 기준은 "신청 성공"이 아니라 **"사용자가 기록한 결과"** 다.

## 3. 단계별 상세

> 단계 식별자는 순번이 아닌 슬러그를 쓴다. 순서가 바뀌어도 식별자는 유지한다.

### `STP-notice-check` 지금 신청할 수 있는 기간인지 확인

- **사용자 행동**: 앱을 열어 홈에서 "지금 상태" 라벨을 본다 (`신규접수 중` / `재등록 중` / `접수 전` / `접수 종료` / `기간 미확인`)
- **터치포인트**: 홈 화면(상태 카드), 재등록 알림(진입 경로), 상태 카드 안의 공식 안내 링크
- **시스템 응답**: 오늘 날짜로 상태를 판정하고 근거 날짜 범위와 **정보 확인일**을 함께 보여준다. 기간 데이터가 없는 센터는 추측값 대신 `기간 미확인`을 보여준다 (AC-G2)
- **생각·감정**: "이번엔 20일부터였나 26일부터였나?" — 확인만 되면 바로 움직일 상태
- **페인포인트 / 이탈 위험**: 기간을 틀리게 알려주면 신뢰를 한 번에 잃는다 → 판정 근거(날짜 범위·확인일·출처)를 라벨과 **같은 카드 안에** 둔다. 모르면 모른다고 쓴다

### `STP-pick-center` 센터와 프로그램 고르기

- **사용자 행동**: 센터 목록에서 다니는 센터를 고르고, 헬스 월회원 / 1일 이용 등 프로그램과 요금·이용시간을 확인한다
- **터치포인트**: 센터 목록 화면, 센터 상세 화면(요금·시간·접수 일정·전화번호)
- **시스템 응답**: 요금·시간 값마다 `확인일 · 출처` 를 붙이고, 60일 이상 지난 값에는 `오래된 정보` 표시를 붙인다 (AC-G8)
- **생각·감정**: "월 5만 2천 원이면 이번 달도 그대로네" — 값이 최신인지가 관심사
- **페인포인트 / 이탈 위험**: 하드코딩된 옛 요금을 사실처럼 보여주면 현장에서 틀린다 → 값과 확인일을 분리하지 않고, 공식 페이지 링크를 항상 함께 둔다

### `STP-prep-account` 막힐 조건 미리 치우기

- **사용자 행동**: 체크리스트 4항목을 확인한다 — 부천시 통합회원 가입 / 본인인증(문자·아이핀) / 14세 미만이면 법정대리인 동의 / 관외 거주 여부. 외국인 구성원이면 토글을 켠다
- **터치포인트**: 신청 준비 화면(체크리스트, 경고 배너, 고정 안내 문구)
- **시스템 응답**: 미체크 항목이 있으면 경고 배너를 띄우되 CTA 를 막지 않는다 (AC-G3). "이 앱은 대신 신청하지 않습니다" 고정 문구를 CTA 위에 둔다 (AC-G5). 외국인 토글을 켜면 현장 확인 안내 + 센터 전화번호 + 현장 접수 시간을 보여준다 (AC-G4)
- **생각·감정**: "자녀 것도 같이 되나?" — 대리인 경로가 보이는지가 중요
- **페인포인트 / 이탈 위험**: 공식 사이트에 들어간 뒤 본인인증에서 막히면 그 달을 놓친다 → 막힐 조건을 **들어가기 전에** 전부 드러낸다. 외국인 경로는 온라인으로 안 끝날 수 있다는 사실을 숨기지 않는다

### `STP-official-apply` 공식 페이지에서 직접 신청

- **사용자 행동**: `공식 신청 페이지 열기` 를 누르고, 열린 공식 사이트에서 로그인·강좌 선택·결제를 **직접** 한다
- **터치포인트**: 외부 브라우저(부천도시공사 공식 수강신청 페이지), 앱으로 돌아오는 복귀 안내
- **시스템 응답**: 센터 코드가 붙은 공식 URL 을 외부 브라우저로 연다 (AC-G1). 열기에 실패하면 오류 배너와 `URL 복사` 를 준다 (AC-G9). 앱은 어떤 화면에서도 아이디·비밀번호·인증번호를 받지 않는다. **향후**: 열기 실패가 연속 2회 이상이면 사용자 신고 없이 버전·단계·실패 유형이 구분되어야 한다 (AC-G11 — 1단계 미구현)
- **생각·감정**: "여기서부터는 내가 하는 거구나" — 경계가 분명해야 안심한다
- **페인포인트 / 이탈 위험**: 공식 사이트가 점검 중이거나 정원이 마감되면 그대로 멈춘다 → 오류·마감 상태에서 돌아올 길(다시 열기, 다른 센터 보기, 알림 걸기)을 앱이 준다

### `STP-record-result` 결과를 가족 기록으로 남기기

- **사용자 행동**: 앱으로 돌아와 결과를 고른다 (`신청 완료` / `대기·미정` / `실패(마감 등)`), 대상 가족 구성원 라벨과 메모(영수증 번호 등)를 적는다
- **터치포인트**: 결과 기록 시트, 신청 기록 목록(구성원 필터)
- **시스템 응답**: 선택값을 센터·프로그램·대상자·해당 월과 함께 저장하고, 기록을 "내가 기록한 값"으로 표기한다. 시트를 닫기만 하면 `미기록` 배지로 남긴다 (AC-G6). 구성원 라벨 필터와 내보내기를 제공한다 (AC-G10)
- **생각·감정**: "굳이 적어야 하나?" — 적는 이유(다음 달 알림)가 보여야 적는다
- **페인포인트 / 이탈 위험**: 기록이 귀찮으면 건너뛰고, 그러면 다음 달 알림도 못 받는다 → 선택 3개만 받고 나머지는 선택 입력. 시트에 "기록하면 다음 재등록 기간을 알려드려요"를 함께 쓴다

### `STP-remind-next` 다음 창구 알림 받기

- **사용자 행동**: 재등록 알림 예약을 확인하거나, 기간 데이터가 없으면 날짜를 직접 입력한다. 다음 달 알림을 받고 이 여정 처음으로 다시 들어온다
- **터치포인트**: 알림 설정 화면, 기기 알림
- **시스템 응답**: 다음 재등록 기간 시작 **1일 전 09:00** 에 로컬 알림을 예약한다. 기간 데이터가 없으면 수동 입력 전까지 알림을 만들지 않고 `알림 없음` 으로 표시한다. 알림이 **이 기기에서만 울린다**는 한계를 화면에 적는다 (AC-G7)
- **생각·감정**: "이제 내가 기억 안 해도 되는 건가" — 이 여정의 보상이 여기서 회수된다
- **페인포인트 / 이탈 위험**: 알림이 안 오거나(기기 설정 꺼짐) 다른 가족 기기엔 안 와서 믿었다가 놓친다 → 알림 권한 거부 상태를 화면에 표시하고, 동기화가 없다는 사실을 명시한다

## 4. 분기·예외 흐름

| 상황 | 처리 | 이어지는 단계 |
|---|---|---|
| 접수 기간이 아님 (`접수 전`) | 상태 카드에서 다음 기간 안내 + 알림 예약 제안. 공식 CTA 는 비활성 대신 "공식 안내 보기"로 바뀐다 | `STP-remind-next` |
| 센터 기간 데이터 없음 (`기간 미확인`) | 추측하지 않고 공식 안내 링크 + 사용자 직접 입력 경로 | `STP-remind-next` |
| 사전 조건 미충족 (통합회원·본인인증 없음) | 경고 배너 + 가입/인증 공식 페이지 링크. CTA 는 막지 않는다 | `STP-prep-account` |
| 14세 미만 대상 | 법정대리인 동의 항목이 체크리스트에 추가로 표시 | `STP-prep-account` |
| 외국인 구성원 | 현장 확인 필요 안내 + 센터 전화·현장 접수 시간. 온라인으로 끝나지 않을 수 있음을 알리고 여정은 앱 밖에서 이어진다 | 여정 밖 종료 (현장 접수) |
| 공식 페이지 열기 실패 / 사이트 점검 | 오류 배너 + `다시 열기` + `URL 복사` | `STP-official-apply` 재진입 |
| 정원 마감 (`실패` 기록) | 실패로 기록하고 다른 센터 보기 제안 + 다음 기간 알림 예약 | `STP-pick-center` |
| 중도 이탈 (공식 사이트만 열고 돌아오지 않음) | 다음 실행 시 "지난번 신청은 어떻게 되었나요?" 로 결과 기록 이어하기 | `STP-record-result` |
| 알림 권한 거부 | 알림 설정 화면에 권한 거부 상태 표시 + 설정 이동 안내. 알림 없이도 홈 상태 카드로 확인 가능 | `STP-remind-next` |
