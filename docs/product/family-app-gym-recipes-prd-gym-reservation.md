## 0. 한 줄 정의

**앱이 신청하지 않는다. 사용자가 제때, 준비된 상태로, 공식 경로에서 신청하게 한다.**

## 1. 문제

확인된 사실(A-3-1)로 접수는 월 단위 창구다: 기존회원 20~25일 / 신규회원 26일~말일 / 개강 1일.
창구를 놓치면 한 달을 기다린다. 그리고 창구 안에 들어가도 **통합회원 가입 + 본인인증**(A-4-1),
**14세 미만 법정대리인 동의**(A-4-2), **관외 거주 50% 가산**(A-4-5) 같은 사전 조건에서 막힌다.

## 2. 용어 — "예약"이 아니라 "수강신청"

사용자 표현은 "헬스장 예약"이지만, 확인된 실제 체계는 시간 단위 예약이 아니라 **월 단위 수강신청/회원등록**이다(A-1-4).
UI 문구는 **"신청"** 을 쓰고, 사용자가 검색할 수 있도록 설명문에서 "예약"을 병기한다.
(시간 단위 대관이 필요한 종목은 `reserv.bucheon.go.kr` 로 안내만 한다 — A-1-3)

## 3. 달성 가치

| 가치 | 이 PRD 가 기여하는 방식 |
|---|---|
| `VAL-dont-miss-window` | 접수 상태 라벨 + 재등록 알림으로 창구를 놓치지 않게 한다 |
| `VAL-official-path-only` | 신청·결제를 전부 공식 사이트로 넘기고, 앱은 자격증명을 다루지 않는다 |
| `VAL-says-what-it-did` | 모든 시설 정보에 확인일·출처를 붙이고, 실패를 화면에 표시한다 |
| `VAL-family-not-solo` | 누가 어느 센터에 신청했는지를 가족 기록으로 남긴다 |
| `VAL-findable-later` | 지난 신청 기록과 영수증 메모를 다시 찾을 수 있다 |

## 4. 범위

**안**: 센터·프로그램 정보 표시, 접수 상태 판정, 사전 준비 체크리스트, 공식 경로 열기, 결과 수동 기록, 재등록 알림, 가족 기록 열람
**밖**: 자동 신청, 자동 로그인, 자격증명 저장, 앱 내 결제, 실시간 정원 조회 (사유는 가치 문서 「범위 밖」 표)

## 5. 자동 예약 가능 범위 — 확인/가정 구분

| 항목 | 상태 | 이 PRD 의 결정 |
|---|---|---|
| 공식 예약/신청 API 존재 | **미확인** (A-6-3) | 없다고 보고 설계한다 |
| 약관의 자동화 금지 조항 | **미확인** (A-6-4) | 확인 전까지 자동화하지 않는다 |
| robots.txt 는 `Allow: /` | **확인** (A-6-1) | 공개 페이지 열람 근거일 뿐, **신청 자동화 허가가 아니다**(A-6-2) |
| 본인인증 필수 | **확인** (A-4-1) | 제3자 앱이 인증을 대행하지 않는다 |
| **결론** | — | **1단계 자동 신청 범위 = 0. 앱은 딥링크까지만 한다.** 변경하려면 D-01(운영기관 확인)이 먼저다 |

## 6. Acceptance Criteria

> 각 AC 는 "검증 방법"에 **관찰 가능한 판정**을 적는다. 플랫폼 의존 항목은 D-02(지원 OS) 결정 전까지 `[OS 결정 대기]` 로 표시한다.

### `AC-G1` 신청은 공식 경로에서만 일어난다
- **설명**: 신청 CTA("공식 신청 페이지 열기")를 누르면 기기의 외부 브라우저(또는 시스템 인앱 브라우저)로 `https://www.best.or.kr/fmcs/271?center=<센터코드>` 가 열린다. 앱은 어떤 화면에서도 부천시 통합회원 아이디·비밀번호·인증번호를 입력받는 필드를 제공하지 않는다.
- **달성 가치**: `VAL-official-path-only`
- **검증 방법**: ① 전체 화면 목록에서 자격증명 입력 필드가 0개임을 확인 ② CTA 탭 → 열린 URL 이 `best.or.kr` 호스트이고 센터 코드 쿼리가 붙어 있음 ③ 앱 로컬 저장소에 비밀번호/세션 쿠키 키가 없음

### `AC-G2` 오늘 기준 접수 상태를 라벨로 보여준다
- **설명**: 센터 상세 화면 상단에 `신규접수 중` / `재등록 중` / `접수 전` / `접수 종료` 중 하나와 **그 판정의 근거 날짜 범위**를 함께 표시한다. 라벨 아래에 "기간 정보 확인일 YYYY-MM-DD"와 공식 안내 페이지 링크를 둔다. 기간 데이터가 없는 센터는 라벨 대신 `기간 미확인 — 공식 안내 보기` 를 표시한다(빈칸이나 추측값을 쓰지 않는다).
- **달성 가치**: `VAL-dont-miss-window`, `VAL-says-what-it-did`
- **검증 방법**: 기기 날짜를 22일/27일/5일/기간 미등록 센터로 바꿔 4가지 라벨이 각각 나오는지 확인. 라벨마다 근거 날짜 범위와 확인일이 함께 보이는지 확인
- **근거**: A-3-1 확인, A-3-2 는 센터별로 다를 수 있다는 **가정** → 기간은 센터별 데이터로 보관한다

### `AC-G3` 사전 준비 체크리스트가 막힐 지점을 미리 드러낸다
- **설명**: 신청 전 화면에 4개 항목 체크리스트를 둔다 — ① 부천시 통합회원 가입 ② 본인인증(문자 또는 아이핀) 완료 ③ 신청 대상이 14세 미만이면 법정대리인 동의 ④ 관외 거주 여부(요금 50% 가산 안내). 미체크 항목이 1개 이상이면 CTA 위에 경고 배너가 보이지만 **CTA 는 막지 않는다**(사용자가 더 잘 알 수 있다).
- **달성 가치**: `VAL-dont-miss-window`
- **검증 방법**: 4항목 모두 미체크 → 경고 배너 표시 + CTA 활성. 전부 체크 → 배너 없음. 항목 ③ 은 대상 나이를 14세 미만으로 설정했을 때만 표시
- **근거**: A-4-1, A-4-2, A-4-5 (전부 확인)

### `AC-G4` 외국인·현장 확인 경로를 막힌 길로 두지 않는다
- **설명**: 체크리스트에 "외국인 등록 구성원" 토글을 두고, 켜면 "증빙서류 지참 후 현장 확인이 필요할 수 있다"는 안내와 해당 센터 전화번호·현장 접수 시간을 보여준다.
- **달성 가치**: `VAL-says-what-it-did`
- **검증 방법**: 토글 켬 → 안내 문구 + 전화번호 + 접수 시간(평일 06:00~21:00 / 토·일·공휴일 09:00~16:00 형태) 표시
- **근거**: A-4-3, A-2-3 (확인)

### `AC-G5` 앱은 "자동 신청을 하지 않는다"를 스스로 말한다
- **설명**: 신청 전 화면과 설정·도움말에 고정 문구를 둔다: **"이 앱은 대신 신청하지 않습니다. 신청과 결제는 부천도시공사 공식 페이지에서 직접 하셔야 합니다."**
- **달성 가치**: `VAL-official-path-only`, `VAL-says-what-it-did`
- **검증 방법**: 두 위치에서 문구가 보이고, 문구가 CTA 보다 먼저 읽히는 위치(CTA 상단)에 있는지 확인

### `AC-G6` 신청 결과를 사용자가 직접 기록한다
- **설명**: 공식 페이지에서 돌아오면 "신청 어떻게 되었나요?" 시트가 뜨고 `신청 완료` / `대기·미정` / `실패(마감 등)` 중 하나를 고를 수 있다. 선택하면 센터·프로그램·대상자·월·선택값이 기록된다. 아무것도 고르지 않고 닫으면 항목은 `미기록` 배지로 목록에 남는다(조용히 사라지지 않는다).
- **달성 가치**: `VAL-family-not-solo`, `VAL-findable-later`, `VAL-says-what-it-did`
- **검증 방법**: 세 선택지 각각 기록 후 목록에서 상태 확인. 시트를 닫기만 했을 때 `미기록` 배지 확인
- **주의**: 앱은 공식 사이트의 신청 성공 여부를 **알 수 없다**(자동화 범위 0). 그래서 기록은 **사용자 신고값**이며 화면에도 "내가 기록한 값"으로 표기한다

### `AC-G7` 다음 재등록 창구 전에 알린다
- **설명**: `신청 완료` 로 기록된 센터·프로그램에 대해, 다음 재등록 기간 **시작 1일 전 09:00** 에 로컬 알림을 보낸다. 기간 데이터가 없으면 사용자가 날짜를 직접 입력해 알림을 만들 수 있고, 입력하지 않으면 알림은 만들어지지 않으며 목록에 `알림 없음` 으로 보인다.
- **달성 가치**: `VAL-dont-miss-window`
- **검증 방법**: 기간 데이터 있는 센터 → 알림 1건 예약됨(예약 목록에서 확인). 없는 센터 → 수동 입력 전에는 0건, 입력 후 1건
- **의존**: 알림 방식(로컬 알림만 vs 푸시)은 D-04 미결정 → **1단계는 로컬 알림으로 쓰되, 기기 1대에만 울린다는 한계를 화면에 표시**

### `AC-G8` 시설 정보는 확인일과 출처를 떼어놓지 않는다
- **설명**: 요금·이용시간·접수시간 등 외부에서 온 값을 보여주는 모든 화면에 `확인일 YYYY-MM-DD · 출처: 부천도시공사` 와 해당 공식 페이지 링크를 붙인다. 확인일이 **60일 이상 지난 값**은 값 옆에 `오래된 정보` 표시를 붙인다.
- **달성 가치**: `VAL-says-what-it-did`
- **검증 방법**: 확인일을 61일 전으로 넣고 `오래된 정보` 표시 확인. 모든 정보 화면에서 출처 링크 탭 → 공식 페이지 열림
- **근거**: A-5-3 (설계 결정)

### `AC-G9` 공식 페이지를 열지 못하면 대안을 준다
- **설명**: CTA 탭 후 브라우저 실행 실패·네트워크 오류 시 오류 배너("공식 페이지를 열지 못했어요")와 함께 **URL 복사** 버튼을 제공한다.
- **달성 가치**: `VAL-says-what-it-did`
- **검증 방법**: 네트워크 차단 상태에서 CTA 탭 → 오류 배너 + 복사 버튼. 복사 후 클립보드 값이 공식 URL 과 일치

### `AC-G10` 기록은 가족이 함께 본다 (1단계 한정 보장)
- **설명**: 신청 기록에는 **대상 가족 구성원 라벨**(역할 또는 이름)이 붙고, 목록에서 구성원별로 필터할 수 있다. 1단계에서는 기기 간 자동 동기화를 보장하지 않으며, 대신 기록 전체를 텍스트로 **내보내기** 할 수 있다.
- **달성 가치**: `VAL-family-not-solo`
- **검증 방법**: 구성원 2명 이상 라벨로 기록 생성 → 필터 동작. 내보내기 결과에 모든 기록이 포함
- **의존**: D-03(가족 공유 인프라), D-07(가족 구성) — **미결정이므로 이 AC 는 "동기화 없음"을 명시적으로 수용한 상태의 AC 다**
